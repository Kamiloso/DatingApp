Prerequisites:
  - Windows / Linux
  - Python 3.12+
  - Docker

Information:
  - To start environment, run menu.bat / menu.sh and follow the instructions in the console.
  - Development mode exposes all containers to localhost and disables backend.

Note:
  - Do not remove the portable folder. It will not regenerate.
  - To refresh portable folder with the latest backend build, run build-portable.bat script (on Windows)
